# Casa Aura

Loja de gesso e têxtil artesanal. Next.js + Tailwind + Supabase, preparada para Vercel.

Veja **docs/ATIVACAO.md** para executar, configurar catálogo, pagamento, frete, e-mails e publicar.

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm dev:next
```

Sem credenciais: catálogo de demonstração, sacola e painel de prévia; compras bloqueadas.
Nunca copie segredos para o código-fonte. Use .env.local ou as variáveis de ambiente Vercel.

Comandos: `pnpm typecheck`, `node tests/security.mjs`, `pnpm build`, `pnpm start`.

As fotografias são ilustrações originais geradas por IA para a apresentação. Não representam o estoque real da Casa Aura. As peças, preços e dimensões são exemplos substituíveis pelo painel.
